### 📌 Ringkasan Eksekutif Proposal
* **Judul Penelitian**: *Implementasi Algoritma Gradient Boosting dan Explainable Artificial Intelligence (XAI) Berbasis SHAP untuk Deteksi Dini Risiko Mahasiswa Drop-Out pada Pendidikan Tinggi*
* **Judul Bahasa Inggris**: *Early Detection of Student Drop-Out Risk in Higher Education Using Gradient Boosting and SHAP-Based Explainable Artificial Intelligence*
* **Domain**: *Educational Data Mining* (EDM), *Learning Analytics*, & *Explainable Artificial Intelligence* (XAI).
* **Dataset**: Dataset Empiris Riil Kaggle / UCI Machine Learning Repository ($N = 4.424$ mahasiswa).
* **Pendekatan Metodologi**: Adaptasi CRISP-DM 6 tahapan, pemodelan *Gradient Boosting* terkalibrasi bobot kelas, validasi *Stratified 5-Fold Cross Validation*, dan dekomposisi nilai *Shapley* (SHAP) untuk transparansi keputusan.
